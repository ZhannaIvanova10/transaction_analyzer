# Transaction Analyzer

Приложение для анализа банковских транзакций из Excel-файлов с использованием реальных API курсов валют и цен акций.

## Возможности

- 📊 Анализ транзакций из Excel-файлов
- 🌐 Получение реальных курсов валют и цен акций через API
- 📈 Генерация отчетов по расходам
- 🔍 Поиск транзакций по различным критериям
- 🏦 Анализ выгодности кэшбэка и инвесткопилки
- 🖥️ Веб-интерфейс с JSON API
